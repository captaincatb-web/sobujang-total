이용 안내

기업을 찾고, 숫자의 기준을 확인하고, 공시 원문으로 돌아가는 순서로 이용하세요.

통합 조사 허브

조사 허브 열기 →에서 모집단 비교, 시장·공정·사업 유형 필터와 조사 작업목록을 사용할 수 있습니다. 작업은 브라우저에 저장되며 완료 표시는 검증 승인이 아닙니다. 참고 허브의 가상 202개 기업과 예시 재무는 반입하지 않았습니다.

1. 기업 탐색

기업명·식별자로 검색한 뒤 국가, 품목, 모집단, 재무 확인 상태로 좁힙니다. 별표를 누르면 해당 브라우저의 관심 기업으로 저장됩니다. 조회 목록 CSV에는 기업 정보와 검증 건수가 담깁니다. 관심 목록은 계정 간 동기화되지 않습니다.

2. 재무 비교

2023~2025년은 회계기간 종료연도입니다. 같은 법인·통화·회계기준·연결/개별 기준의 매출과 영업이익 6개 값이 승인된 기업만 비교합니다. 원통화 금액이며 원화 환산이나 기업 간 합산은 하지 않습니다.

증감률 = (당기 ÷ 전기 − 1) × 100. 전기가 0 이하이면 표시하지 않습니다. 원문 단위가 백만이면 원통화 금액 = 원문 값 × 1,000,000입니다.

3. 근거 확인

기업 상세 → 근거 확인에서 회계기간, 원문 단위, 출처 URL, 표·행·열 및 문서 해시를 확인합니다. 기업 분류 확인과 재무 확인은 별도입니다. 기존 비교 자료 857건은 모드별 중복이 포함된 관측 건수이며 기업 수가 아닙니다.

4. 산업지도

법인과 사업장은 별도로 관리합니다. 근거와 좌표가 승인된 위치만 표시하며, 좌표가 없으면 임의로 도시 중심점에 표시하지 않습니다. 빈 지도는 데이터 미확보 상태를 의미합니다.

5. 매일 정기 업데이트

매일 오전 7시 한국시간(전날 22:00 UTC)에 GitHub Actions가 개발 저장소의 승인 스냅샷을 확인합니다. 안전성 검사를 통과한 변경만 배포 브랜치에 반영합니다. 변경이 없으면 확인 일시만 갱신합니다. GitHub 실행 지연이나 서비스 장애로 정시 실행이 보장되지는 않습니다.

자동 업데이트는 공시 원문 신규 수집·자동 검증을 의미하지 않습니다. 수집·검토 담당자가 승인 자료를 갱신해야 재무 값이 바뀝니다. 오류가 발생하면 기존 성공 데이터는 유지하며 Actions에서 실패 원인을 확인합니다.

6. 수정과 한계

웹 배포본은 읽기 전용입니다. 입력·검토·승인·철회는 로컬 조사 콘솔에서 진행합니다. 전체 해외 기업 전수 재무, 사업장 좌표, 모든 모바일 환경 검증이 완료된 서비스는 아닙니다.
