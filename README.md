# 반도체 공급망 인텔리전스 · sobujang-total

국내외 반도체 소재·부품·장비 기업 조사, 공시 기반 재무 검증, 산업지도 통합 플랫폼 개발 저장소입니다.

## 현재 구현: 재무 검증 기반

- 기존 CSV 반입기 재사용 및 증빙·기준·통화·단위 검증 강화
- 원문 숫자/단위 보존, 반입 값은 기본 `unverified`
- 별도 원문 검증·승인 계약 및 변경 시 승인 무효화
- 미승인·중복·기준 혼재 시 릴리스 전체 차단
- 공개 후보는 허용 필드만 반환, CLI는 건수와 오류 코드만 출력
- Python 3.11/3.12 오프라인 테스트 CI (배포 기능 없음)

```bash
python -m unittest discover -s tests -v
python scripts/growth/verified_release.py /absolute/private/release-input.json
```

테스트와 사전 검증은 외부 패키지 없이 실행합니다. 기존 수집 CSV 반입기를 실제 실행할 때는 requests, 엑셀 읽기에는 openpyxl이 별도로 필요합니다.

[재무 계약·제약·재사용 출처](docs/financial-contract.md)

## 운영 원칙

이 저장소는 공개입니다. 비공개 원천·내부 명단·키를 커밋하지 않습니다. 실제 미검증 수치를 생성하거나 공개하지 않습니다. 원문 확인과 공개 승인은 분리합니다.

현재 모듈은 오프라인 기반이며 UI/DB/인증된 승인 시스템 또는 기존 공개 사이트에 연결되지 않았습니다. 신뢰된 운영자만 승인 manifest와 공식 호스트 정책을 제공해야 합니다. 해시는 검토자 인증이나 실제 원문 검증을 대신하지 않습니다.
