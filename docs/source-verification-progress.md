확인일: 2026-11-15. 이 문서는 개발용 검증 기록이며 운영 배포 승인이 아니다.

## 완료 범위와 계산

- 기존 기업 마스터 189개 + ASML 1개 + Tekscend 1개 = 191개 엔터티.
- 원문 대조 및 승인된 재무: 2개 기업 × 3개 회계연도 × 2개 지표 = 12개 사실 레코드.
- 완전한 3개년 비교 패널 2개. 서로 다른 통화이므로 기업 간 합산 없음.
- 기존 비교 자료 857개는 파일별 관측 레코드 수이며 고유 기업 수가 아니다. 이 수를 검증 완료 기업 수로 표시하지 않는다.
- 좌표까지 원문 검증·승인된 사업장은 0개. 지도에 임의 핀을 생성하지 않는다.

## 아직 완료되지 않은 범위

전체 해외 기업의 2023~2025 전수 검증, 공식 사업장 좌표 전수 확보, 지도 군집화·이동 UX, 실제 모바일 브라우저 검증은 완료되지 않았다. 운영 서비스용 인증/권한 서버도 이번 로컬 콘솔 범위에 포함되지 않는다. 현재 테스트 통과를 이 작업들의 완료로 해석하면 안 된다.

후속 순서: 기간/지표 정의 모델 확장 → 보류 기업별 원문 대조 → 정확한 법인 연결 → 공식 주소/좌표 근거 확보 → 모바일·지도 검증 → 사용자의 화면/수치 검토 → 승인된 PR만 순서대로 병합. main 병합과 배포는 별도 승인 전 실행하지 않는다.
